## Key Architectural Insights Surfaced by the Loop

1. **Plan-level reliability-protocol bug**: the original Phase 3 plan called for `isWritable()`-drop on the reliable path (Commit A as written). Gemini correctly identified this as a protocol violation (no seqNo burned → client can't detect the gap → silent data loss). Removed the drop; the existing SlowConsumerHandler ladder is the correct mechanism. Test that asserted the bad behavior was deleted and replaced with `WebSocketDrainHandlerReliableNoDropTest`.

2. **DWRR semantic correctness**: my initial implementation reset the deficit to zero unconditionally on a zero-fragment cycle — which wiped accumulated debt from prior over-polls and broke RFC 8290 fairness. Gemini caught it; the fix gates the idle-reset on `if (budget > 0)` so debt is preserved across cycles until repaid.

3. **End-to-end command pipeline wiring**: the R1 wiring of admission collaborators introduced separate command queue / ack queue / pool instances on the egress thread vs the server, severing the browser→cluster command path AND the THROTTLED ack back-channel. Gemini surfaced as CRITICAL; the fix shares all three instances.

4. **Test-helper FQCN drift**: Sonnet sub-agents writing tests used inline FQCNs in helper method return types + `instanceof` patterns. Two full FQCN sweeps (R1 + R2) caught all 12 sites. Worth noting for future agent prompts.
