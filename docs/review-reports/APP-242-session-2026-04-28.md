## Lessons / process notes

1. **Admin merge raced Gemini round 3 by 71s** — round 3 surfaced 2 MEDIUM findings on already-merged code. The orchestrate skill spec mandates polling Gemini until zero comments before declaring convergence; the user explicitly overrode this with `merge pr rebase admin`. Captured the post-merge findings in APP-243 to avoid losing them.

2. **Orchestrate loop produced strong correctness signal** — across 4 iterations the agents surfaced 4 critical-level concurrency bugs (CHM segment-lock misuse, reverse-lock-order deadlock, non-atomic seqNo, non-thread-safe ring buffer) that local Agent A alone (constraint checker) did not catch. Agent B (general quality) and Gemini both materially improved the diff. This validates running both review channels together.

3. **Two-phase sweep pattern** (R2) is reusable: when a sweeper iterates a CHM and a hot-path mutates the same map under a dedicated lock, collect candidates without the lock in phase 1, then take the lock + CAS-remove in phase 2. Avoids reverse-lock-order deadlocks.

4. **Approximate-LRU sampling** (R3 + R4) replaced both the outer (100k user) and inner (10k ClOrdID per user) full scans with a constant-cost 64-entry sample. Pattern documented in `EVICTION_SAMPLE_LIMIT` and re-used inside `UserDedupState.evictOldest`.

5. **The orchestrate-before-push hook landed mid-session** (`enforce-orchestrate-before-push.sh`) — see memory `feedback_orchestrate_always.md` and `feedback_orchestrate_mandatory_in_plans.md`. Future sessions cannot push without `LOCALLOOM_ORCHESTRATE_VERIFIED=1`, eliminating the judgment call that originally led to skipping `/orchestrate` after `/review`.
